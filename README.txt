المصحف الإلكتروني - النسخة المحسّنة بالتجويد

الملفات:
- index.html : واجهة التطبيق والتصميم
- app.js : القراءة والبحث والتفسير والصوت والتجويد والحفظ
- sw.js : التخزين المؤقت وتشغيل ملفات التطبيق دون إنترنت
- manifest.json : إعدادات تثبيت التطبيق
- icon.svg : أيقونة التطبيق

طريقة التحديث:
1) فك ضغط الملف.
2) ارفع جميع الملفات إلى نفس مجلد الموقع واستبدل الملفات القديمة.
3) افتح الموقع من رابط HTTPS.
4) من القائمة أعلى الصفحة اختر "ألوان التجويد".
5) افتح أي سورة؛ سيحمّل التطبيق طبعة quran-tajweed من AlQuran Cloud ويعرض علامات الأحكام بألوانها.

مصدر التجويد:
- إصدار quran-tajweed من AlQuran Cloud.
- بيانات الإصدار تحتوي على علامات أحكام التجويد، ويحوّلها التطبيق إلى ألوان داخل الآيات.
- لا يعتمد التطبيق على تخمين الأحكام أو Regex لتحديد مواضعها.

ملاحظات:
- يحتاج وضع التجويد إلى اتصال بالإنترنت عند أول تحميل للسورة.
- زر حفظ القرآن دون إنترنت يحاول حفظ النص العادي وإصدار التجويد لكل سورة.
- إذا تعذر تحميل إصدار التجويد، تظهر رسالة واضحة ويمكن الرجوع إلى النص العادي.
- البحث والتفسير يحتاجان اتصالًا عند عدم وجود بيانات مخزنة.
- يلزم HTTPS أو localhost لتشغيل Service Worker.
- لم أتمكن من اختبار اتصال API الحي من بيئة التحرير؛ تم التحقق من صيغة الكود نحويًا، ويجب تجربة وضع التجويد بعد رفع الملفات على موقعك.
